# Data

The study uses one open dataset, which is not redistributed in this repository.

Espinosa, P., Lledo, J., & Atance, D. (2026). A detailed dataset of motor insurance policies with
coverage-specific financial information (Version 1) [Data set]. Mendeley Data.
https://doi.org/10.17632/sw4jmdb2sm.1

354,140 policy-year records, 185,678 policyholders, three years (2022 to 2024), 47 variables, semicolon separated.

Download the file from the DOI above and save it here as `data/Dataset_of_motor_insurance_portfolio.csv`, or set the
environment variable `RGA_DATA` to its path. Check the dataset licence on the DOI page before reuse.

`human_questions_TEMPLATE.csv` shows the format for optional analyst-written questions. The reported benchmark does not
use them.
